# RS7 Işık v1.0.1

v1.0.0 için taşınabilirlik düzeltmesi. Sistem tepsisi, Deniz dalgası, Türkçe kontroller ve ayarları hatırlama korunur.

- Windows MSVC derlemesinde C/C++ çalışma zamanı EXE içine statik bağlanır. Ayrı Visual C++ Redistributable kurulumu gereksinimi kaldırılır.
- Test ve sürüm doğrulaması yine yayın öncesinde çalışır. EXE ile SHA-256 dosyası birlikte sunulur.

`RS7-Isik-v1.0.1-Windows-x64.exe` dosyasını açın. Eski sürüm tepside açıksa önce sağ tık → **Tamamen çık** seçin. X veya küçültme, uygulamayı tepside çalışır bırakır; gerçek çıkış yalnızca tepsi menüsündedir.

Hedef: Windows x64, ATK RS7 Air ANSI. Fiziksel test cihazı firmware 2.02 / USB 373b:1220. Fn, diğer klavyelerin de tetikleyebilmesi ve EXE’nin dijital imzasız olması gibi v1.0.0 sınırları geçerlidir. Diğer firmware varyantları ve uzun süreli saha testi için tam kararlılık taahhüdü verilmez.
