# RS7 Işık v1.1.0-preview.2

Henüz kararlı GitHub Release değildir.

- Rust motorunda 64 Türkçe efekt seçeneği; adları farklı olan ortak efekt aileleri birleştirildi.
- Arama (İ/ı/ş/ç dahil), yedi kategori, sayfalama, açıklamalar.
- Tuş sönümü, artı, alev, patlama, bütün klavye tepkisi ve yazım ısı haritası.
- Windows ses çıkışına tepki, ekran renkleri, işlemci/bellek doluluğu ve saat.
- Kullanılmayan canlı kaynaklar durur; kaynak okuma USB döngüsünden ayrıdır.
- Önizleme modu USB/global tuş kancası kullanmaz ve ayar yazmaz.
- Siyah/beyaz/lime arayüz; X ile sistem tepsisi asıl EXE'de korunur.

16 otomatik test ve bir yerel Windows kaynak testi geçti. Tüm 64 mod fiziksel RS7 üzerinde ayrı ayrı denenmedi. [Katalog ve sınırlamalar](../docs/EFEKT-KATALOGU.md). Kararlı sürüm v1.0.1 olarak kalır.
