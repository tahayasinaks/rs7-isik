# RS7 Işık v1.0.0

Rust ile yazılmış yerel Windows x64 aydınlatma uygulaması. Önceki 0.x geliştirme sürümlerinden sonraki ilk ana yayın.

- **Sistem tepsisi:** X ve küçültme pencereyi gizler; çalışan efekt devam eder. Simgeye tıklayarak pencereyi açın. Sağ tık: Aç, Efekti başlat, Efekti durdur, Tamamen çık.
- **Deniz dalgası:** mavi/turkuaz su üzerinde parlak köpük tepeleri. Özel tek/iki renk seçimi de desteklenir.
- **Ayarlar:** hız 0.20×–3.00×, parlaklık %0–100, renk seçimi. Tam çıkışta ayarlar kaydedilir ve sonraki açılışta geri yüklenir. Bağlantı ve efekt başlangıcı kullanıcı kontrolündedir.
- **Dayanıklılık:** tek uygulama örneği, Explorer yeniden başlarsa tepsi simgesini geri ekleme, tepsi kullanılamıyorsa pencereyi erişilemez biçimde gizlememe, gecikmiş USB karelerini biriktirmeme.
- **Gerçek çıkış:** tepsi menüsündeki Tamamen çık, USB akışını temiz biçimde sonlandırır. Klavye kendi ATK aydınlatmasına dönebilir.

## Kullanım

`RS7-Isik-v1.0.0-Windows-x64.exe` dosyasını açın. Kurulum veya Rust/Electron gerektirmez. ATK HUB ve eski RS7 Işık sürümlerini kapatın. Klavyeyi bağla → mod seç → Başlat.

## Bilinen sınırlar

- Hedef ATK RS7 Air ANSI. Fiziksel doğrulama firmware 2.02 / USB 373b:1220 üzerinde; diğer listelenen varyantlar henüz fiziksel test edilmedi.
- Fn ve yükseltilmiş erişimle çalışan bazı uygulamalarda tuşa tepki desteklenmeyebilir. Diğer bağlı klavyeler de tetikleyebilir.
- Tam çıkışta özel efekt çalışmaz; firmware değiştirilmez. Tepsiye küçültmek tam çıkış değildir.
- EXE dijital imzalı değildir. Tema bu sürümün kapsamı dışındadır.
